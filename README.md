# the collective

**Intelligent Management & Automation Matrix** — a complete global website built around the supplied master brand kit, six connected capabilities and four owner-supplied portfolio projects.

## Development

Node.js 24 is recommended. From the repository root:

```sh
npm ci
npm run build
npm run dev
```

The server listens on port 3000; use `PORT` to override it. In a restricted filesystem environment, `npm ci --cache /workspace/.npm-cache` keeps the cache writable. The development server serves the clean page routes, legacy redirects, assets and local API handlers.

```sh
npm test
VERIFY_ORIGIN=http://127.0.0.1:3000 npm run verify:live
```

The eight automated tests cover all 37 pages, metadata, internal links and images, global content, redirects, USD pricing, dashboard tabs, filters, service recommendations, form validation, provider-failure recovery and the automation demo. The live checker verifies served pages, assets, redirects and actual missing-page behavior.

`dist/`, `vercel.json`, and Cloudflare route maps are generated by `npm run build`. Edit the source, then rebuild. Commit the generated output alongside source changes. The old runtime, component templates and former visual identity are retired. No third-party advertising or analytics script is loaded by default.

## Vercel

Import `digitalburjos-oss/ThaImamCollective` into Vercel. Use **Other** as the framework, repository root as the root directory, **Node.js 24.x**, `npm ci` to install, `npm run build` to build and `dist` as output. The committed `vercel.json` provides page rewrites, legacy redirects and security headers. The `api/` directory supplies Node serverless endpoints. Unknown routes receive a real 404 and the branded `404.html` page.

Connect `theimamcollective.com` and optionally its `www` alias in the project’s Domains settings, using the DNS records Vercel provides. Canonicals, structured data and sitemap use the supplied brand domain.

## Email and contact

Information: `info@theimamcollective.com`. Project enquiries: `contact@theimamcollective.com`. Support: `support@theimamcollective.com`. The user-provided phone remains an international WhatsApp contact.

Automatic delivery requires `RESEND_API_KEY` in the deployment host’s secure environment settings and a verified sending domain. Defaults are `the collective <info@theimamcollective.com>` for the sender and `contact@theimamcollective.com` for project notifications. Optional `MAIL_FROM`, `CONTACT_TO` and `RESEND_SEGMENT_ID` override these. The existing provider integration is preserved; no credentials are embedded or provisioned by the build.

Contact validation runs before submission. A provider outage displays an explicit “not sent” message and offers an optional unsent draft in the visitor’s email app. Newsletter failure never appears as a successful subscription. Demos use only local sample data and stop at human review. Tests mock provider calls; no real enquiry or newsletter message was sent during verification.

## Scope and publication

All 37 pages are complete marketing/editorial pages. Academy, Talent and Jobs do not claim an authenticated learning system, candidate database or hiring platform. Pricing is indicative and in USD; annual totals are exactly twelve monthly estimates, with implementation, usage and taxes separate. Confirm commercial terms, mailbox setup and the privacy notice against actual business arrangements before public release.

Project previews are original interface studies, not live screenshots or customer-result claims. The source repositories are linked on each project story. See `docs/REFERENCE-RESEARCH.md`, `docs/image-assets.json` and `docs/VALIDATION.md` for provenance and verification details.
